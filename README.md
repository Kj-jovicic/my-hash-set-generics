# MyHashSetApp

Dieses Projekt ist die Vorlage für die Übung "Erweiterung einer Hashtabelle (HashSet)".
Was genau zu tun ist, steht in der Angabe (Word-Dokument), die ihr separat bekommt.

## Was zu tun ist

Es gibt eine einfache Hashtabelle (`MyHashSet`), die Lehrpersonen speichert. Diese Grundversion funktioniert bereits.
Eure Aufgabe ist es, sie um einige Dinge zu erweitern, zum Beispiel:

- dass man mit `foreach` über das Set iterieren kann
- dass zwei Lehrpersonen als "gleich" erkannt werden, wenn Fach und Wochenstunden übereinstimmen
- dass man die Lehrpersonen nach verschiedenen Kriterien sortieren kann
- dass die Daten aus der Datei `lehrpersonen.txt` eingelesen werden (inklusive kaputter/leerer Zeilen, die übersprungen werden müssen)
- ein paar weitere Kleinigkeiten (Queue/Stack-Szenario, eigene Iteratoren)

Im Code sind an den passenden Stellen `TODO`-Kommentare, die zeigen, wo ihr ansetzen müsst.
